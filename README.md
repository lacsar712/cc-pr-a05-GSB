# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

送检必须附带青、品、黄三色偏差（毫米），缺少黄版直接退回、不进队列；黄版数字进入任务后即锁死。青、品、黄三色绝对偏差都不超过现行允差（0.15 mm）才判套准。

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 再送一条青偏差 0.5 的印张，状态先是待处理，随后变成套不准。
3. checker 没有送检栏（无送复核按钮），但能看到总表里的黄版列，无法投队。
4. 三色判定（现行允差 0.15 mm）：
   - 投 青 0.05、品 0.04、黄 0.20 → 黄超出允差，判**套不准**；
   - 把黄改成 0.01 再投 → 青品黄都在允差内，判**套准**。
5. 送检不带黄版（缺 `yellow_mm` 或为 null）直接被接口退回，队列里不出现该任务。
6. 菜单「三色偏差」页包含：黄版说明、送检栏、已锁死三色一览总表（原总表加一列黄，不算新页）。
