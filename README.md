# 印刷套准复核台

接口只把印张偏差放进待处理队列。另一个进程用行锁领走一条，算出套准或套不准后再写回。页面每隔一秒看一次，直到结论出现。

送检必须附带青、品、黄三版偏差（毫米）。青品黄三色绝对值都不超过现行允差 0.15 毫米才判套准；缺少黄版直接退回；三色数字进入任务后锁死，不可再改。菜单里的三色偏差页有黄版说明、送检栏和已锁死三色一览总表。

## 验收

1. printer 登录后稍等，封面-01 变成套准，内页-09 变成套不准。
2. 送检少填黄版，直接退回，提示"缺少黄版偏差"。
3. 允差 0.15 时投青 0.05、品 0.04、黄 0.20，状态先待处理，随后变成套不准；黄改成 0.01 再投，变成套准。
4. 已入队任务的三色数字锁死，只能看不能改。
5. checker 看得到黄版列，但送检栏是灰的，投不了队。
6. 菜单有三色偏差页：黄版说明、送检栏、已锁死三色一览总表。
